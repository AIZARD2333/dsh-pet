## 这个分支多了什么：干活模式

桌宠的对话默认只是一次 LLM 闲聊。这个分支加了一条「真干活」的路：
消息以 `!`、`！` 或 `/work` 开头，就会交给一个真正的 DSH agent 会话（带工具、带工作区）：

```
!把 README 里的错字改掉，改完跑一遍测试
```

宠物会先回一句「收到」，一轮结束后把结果写进气泡和对话记忆。
完整说明、权限前提（完全访问、没有审批）与限制见 **[WORK.md](./WORK.md)**。
